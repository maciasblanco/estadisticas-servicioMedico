# Sistema de Gestión Médica

Sistema en VBA/Excel para registro y estadísticas de atenciones médicas.

## Estructura
- `Codigo_Fuente/` — módulos `.bas` y formularios `.frm`
- `PromptParaSistemas.txt` — notas del proyecto
- `Servicio_Medico_estadisticas.xlsm` — libro principal (no versionado si contiene datos)

## Requisitos
- Excel con macros habilitadas
- "Confiar en el acceso al modelo de objetos del proyecto de VBA" activado
- Carpeta `Codigo_Fuente/` junto al `.xlsm`

## Instalación
1. Abrir el `.xlsm`
2. Ejecutar `ImportarTodoElSistema`
3. Login inicial: `ADMIN` / `Admin2026!`[core]
